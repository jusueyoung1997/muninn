本文是一份持续补充的学习笔记，阅读起点是苏剑林的[《生成扩散模型漫谈（十三）：从万有引力到扩散模型》](https://kexue.fm/archives/9305)。先围绕其中的 **Poisson Flow Generative Models（PFGM）** 建立理解框架，其他流模型留待后续讨论。

## 1. 从“生成一个样本”到“搬运一个分布”

生成模型需要把容易采样的随机变量变成符合数据分布的样本。用 ODE 描述这个过程，就是让一个向量场不断改变样本的位置。

阅读时需要同时回答三个问题：从什么分布出发、沿什么方向运动、什么时候停止。仅仅让轨迹靠近训练数据，还不足以证明输出的概率分布正确。

## 2. 引力直觉：数据能否成为场的源？

苏剑林的文章从吸引场入手：把数据当作源点，把生成过程想成沿场线靠近数据。远离数据时，整体场近似径向，便于构造简单的初始分布；但直接在原空间运动，仍可能把不同起点压向少数位置。[原文的直观解释](https://kexue.fm/archives/9305)

这里的“沿场线走”是**速度由场决定的一阶动力学**，不能直接等同于有惯性的牛顿运动。

## 3. 增加一维，明确生成的终点

把 d 维数据 x₀ 嵌入 d+1 维空间，位置变成 (x₀, 0)。记新增坐标为 z，数据分布为 p_data，则源分布为：

```text
ρ(x, z) = p_data(x) δ(z)
```

δ 表示狄拉克 delta；所有真实数据都在 z=0 平面。这里的 z 对应原文使用的 t，另用 τ 表示沿轨迹运动的参数。

按吸引方向定义场，并省略共同的正常数，可以写成：

```text
K(x, z; x₀) = −(x − x₀, z) / (‖x − x₀‖² + z²)^((d+1)/2)
F(x, z) = E[x₀ ∼ p_data] K(x, z; x₀)
        = (F_x, F_z)
```

原论文采用电场记号；本文用吸引场 F，对应其电场 E 的反方向。后面的分量比值不受这个整体符号影响。

从公式可以直接检查：只要 z>0，每个源对 F_z 的贡献都为负。因此沿吸引场运动时 z 单调减小，可以把到达数据平面作为终点。

增维后的分布恢复结论依赖通量守恒及相应条件，不能仅凭“不会互相抵消”推出；严格论证见[原论文第 3.1 节](https://arxiv.org/html/2209.11178v3#S3.SS1)。

## 4. 以高度为自变量，得到生成 ODE

把轨迹方程分别写出，再用链式法则消去 τ：

```text
dx/dτ = F_x(x, z)
dz/dτ = F_z(x, z)

dx/dz = F_x(x, z) / F_z(x, z)
```

采样时从较大的 z=T 向 z=0 积分。由于步进方向是 z 递减，不能看到分量比值就再额外添加一个负号。

这也说明，若用同一个正标量函数 a(x,z) 同时缩放所有场分量，则：

```text
(a F_x) / (a F_z) = F_x / F_z
```

所以生成轨迹关心的是场的方向。这个性质为学习归一化场提供了依据。

## 5. 初始分布：为什么不是高斯？

PFGM 从远处上半球面的均匀方向分布出发。为了统一积分起点，可以将方向径向投影到 z=T 平面；所得密度具有重尾：

```text
p_T(x) ∝ T / (‖x‖² + T²)^((d+1)/2)

令 r = ‖x‖，则径向密度为：
p_T(r) ∝ r^(d−1) T / (r² + T²)^((d+1)/2)，r ≥ 0
```

注意两种密度不同：径向采样多了球坐标的体积因子 r^(d−1)。推导依据见[论文第 3.3 节与附录 A.4](https://arxiv.org/html/2209.11178v3#S3.SS3)。

一个可自行验证的等价采样方法是：独立采样 g∼N(0,I_d)、h∼N(0,1)，再令 x=Tg/|h|。理由是 (g,|h|) 的方向在上半球均匀，而投影到 z=T 时比例因子正是 T/|h|。

该方法描述理想先验；h 很小时会产生很大的样本。实际使用有限 T、数值截断及近似场时，需要单独评估误差。

## 6. 训练：用数据估计场，再让网络拟合

理论场需要对整个数据分布取期望，实际训练只能用有限批次估计。将大批次记为 B，在查询点 q=(x,z) 处构造方向目标，可以概括为：

```text
F_B(q) = mean[xᵢ ∈ B] K(q; xᵢ)
v_B(q) = √d · F_B(q) / (‖F_B(q)‖ + ε)
loss   = mean[q] ‖v_θ(q) − v_B(q)‖²
```

这只是训练主干，省略了数值缩放和具体扰动实现。查询点由数据扰动产生，场目标则由较大的数据批次计算；不能把查询点的单个来源样本直接当成整个场的监督。[原论文第 3.2 节](https://arxiv.org/html/2209.11178v3#S3.SS2)

归一化是非线性操作，一般有 E[Normalize(F_B)] ≠ Normalize(E[F_B])。因此有限批次的方向目标存在估计偏差，批次大小与数值稳定性值得专门研究。

## 7. 把训练和生成串起来

```text
训练：数据批次 → 构造查询点 → 估计并归一化场 → 回归网络输出
生成：采样 x_T → 用 v_θ,x / v_θ,z 求解 ODE → 得到接近 z=0 的样本
```

实现时通常停在小的正数 z_min，并处理靠近数据平面的数值问题。需要区分理论上的理想场、神经网络的估计误差，以及 ODE 求解器的离散误差。
