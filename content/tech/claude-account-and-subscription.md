**一句话原理：用的时候像当地家宽用户，付钱的时候让 Google 替你出面。**

Claude 识别账号特征的方式很多，**本方案只解决两个维度**：**使用时的信息**（你在哪里用 —— IP 加设备的语言／时区／地区）、**支付时的信息**（谁在替你付钱，靠账单暴露）。

把这两个维度做干净，能挡掉大部分风控。

⚠️ 只是降低风险，不是 100% 不封；封号、扣款风险自行评估。

## 先搞懂原理：本方案只解决两个问题

Claude 判断账号异常会看很多特征。本方案不追求全覆盖，只处理下面这两个最容易暴露的维度；其余特征（行为习惯、邮箱、设备指纹等）不在范围内，也不用你做额外操作。

|方案处理的维度|出问题的样子|本方案怎么做|
|---|---|---|
|使用时的信息：IP \+ 设备环境（语言／时区／地区）|IP 脏或国家乱跳；语言、时区和 IP 对不上 → 秒封／风控|用美国或新加坡的**住宅原生 IP**固定不换；设备语言、时区、地区跟节点国家对齐|
|支付时的信息：付款人是谁、卡在哪里|国内卡 \+ 地址对不上 → 付款失败或被风控|用 **Google Play 内购**订阅：Claude 只拿到 Google 的订阅记录，看不到你的卡和地址|

**一条铁律：从登录第一个账号开始，到以后每次使用，代理全程开着，国家不许换。**

除这两个维度，不用折腾浏览器指纹、硬件参数这类更深的伪装。

## 使用环境：把自己变成当地用户

### 搞到一个「干净」的 IP

- 国家选**美国或新加坡**，二选一，**选定后不要换**（美国最常用）。

- 我用的是 **LisaHost**（自营 VPS，有美国住宅 IP／家宽产品），完整搭建步骤见文末附录。

- **不要**用免费机场、公共代理、共享节点，IP 一脏就白干。

### 检查 IP 干不干净

手机连上代理后，打开这三个站点：

- [**https://cleanip\.io/claude**](https://cleanip.io/claude)：给出 VPN／代理／机房标记和信誉评分，分越高越干净。

- **ip\.sb** 或 **ipinfo\.io**：国家必须是你要伪装的那个；

- **iprisk\.top**：**分数 ≥ 95**，类型显示**住宅／家宽（Residential / ISP）**，不是 Hosting、Datacenter、Cloud；

有「Proxy/VPN detected」或分数低，就换节点。

### 把设备也调成当地的样子

IP 之外，设备环境也要和节点国家一致：**语言、时区、地区三处对齐**。否则「美国 IP \+ 中文系统 \+ 中国时区」本身就是个明显的矛盾特征。

|设备|时区|语言与地区|
|---|---|---|
|macOS|系统设置 → 通用 → 日期与时间 → 关掉自动设置，选美国时区|通用 → 语言与地区 → 首选语言加 English，地区选 United States|
|安卓|设置 → 系统 → 日期和时间 → 关掉自动，选同一时区|设置 → 系统 → 语言和输入法 → 语言 → 添加 English \(United States\)|
|iOS|设置 → 通用 → 日期与时间 → 关掉自动设置|设置 → 通用 → 语言与地区 → 语言 English，地区 United States|

- 时区要和节点国家对得上：美国节点选美国时区（Los Angeles／New York），新加坡节点选 Singapore；

- 浏览器语言跟着系统走，单独设过语言的（比如 Chrome）检查一下，别留中文优先；

- 应用商店地区也要对齐：Google Play 的查法见「支付与防封」那一章；iPhone 的 App Store 在「设置 → 你的名字 → 媒体与购买项目 → 国家/地区」。

### 客户端配置（照抄即可）

**macOS：Clash Verge**

1. **关闭 IPv6**（否则 IPv6 流量可能绕过代理暴露真实 IP）；

2. 模式选**规则（Rule）**；

3. 打开**系统代理（System Proxy）**；

4. （可选）打开 **TUN 模式**：接管所有软件流量，连不认系统代理的程序也走代理。

TUN 模式可能让部分网站打不开；网络不通就把报错丢给国产大模型，让它帮你改 Clash 路由规则。

**安卓：Clash Meta** —— 导入订阅 → 选同国家节点 → 打开开关。

**iOS：Shadowrocket（小火箭）** —— 导入订阅 → 选同国家节点 → 打开开关。

> 三个平台用**同一批节点、同一个国家**。

## 支付与防封：按顺序做完

**先说清一件事：Google 账号和 Claude 账号是两个不同的账号，是解耦的。**

Google 账号只负责付钱，Claude 账号只负责订阅和使用。Google 账号用 A 邮箱，Claude 账号可以完全是另一个 B 邮箱，两者不需要是同一个。

但它们之间的订阅关系是 **1:1**：**一个 Google Pay 账号只能订阅一个 Claude 账号。**

### 准备 Google 账号，确认国家/地区

**Play 国家/地区、付款资料国家/地区，必须是美国或新加坡，且和节点国家一致。**

**手机上三条查法任选一条：**

1. **Play 商店查**：右上角头像 → 设置 → 常规 → 账号和设备偏好设置 → 国家/地区；

2. **Google 账号查**：手机「设置」→ Google → 管理你的 Google 账号 → 付款和订阅 → 付款方式；

3. **网页版查**：手机浏览器打开 pay\.google\.com → 左上角菜单 → 设置 → 付款资料。

**最快的判断：**Play 里付费应用显示 US$ 就是对了，显示人民币就是不对。

地区不对就新建一个对应国家的付款资料，账单地址填该国地址。**Play 改区 90 天只能改一次**，想清楚再动。

### 在 Google Pay 上绑一张卡

- 路径：Play → 头像 → 付款和订阅 → 付款方式 → 添加信用卡或借记卡（也可在 pay\.google\.com 添加）。

- 用**能付美元的卡**：Visa／Mastercard 或虚拟卡平台的美元卡。

- 账单地址填**付款资料所在国**的地址。

- 绑完确认卡片能选中、状态正常。

### 手机先探路

1. 手机**先开代理**，确认还是那个国家；

2. 装官方 **Claude App**（开发者 Anthropic），用**公司邮箱**注册（能收信即可）；

3. 聊两句，看会不会秒封；没封就继续。

### 电脑端再探路

1. 电脑**先开代理**，再打开 **Claude 桌面端**；

2. 同样聊两句，确认没封。

### 等一下，再付钱（关键一步）

- 免费版先正常用 **1\~3 小时**，**不要注册当天就付款**；

- 在**手机 Claude App 里**点升级，**用 Google Play 内购付款**（别在网页版输卡）；

- 付完自查：Play「付款和订阅 → 订阅」显示 Active 和下次扣费日，Claude 里显示 **Pro**。

### 以后正常使用

**每次使用都开代理**，节点不换、国家不换，也不要频繁换国家或换 IP。

## 最容易踩的四个坑

|现象|原因|怎么办|
|---|---|---|
|注册就被封|IP 脏（机房／免费代理），或国家乱跳|换住宅节点，固定国家，换新邮箱重来|
|绑卡失败或提示地区不支持|Play 地区、付款资料、IP 三者不一致|三处对齐成同一个国家再试|
|用几天后被封|中途关代理裸连，或换了国家登录|全程开代理，节点固定|
|开 TUN 后打不开网站|Clash 路由规则冲突|把报错发给国产大模型改规则|

## 常见问题

### 想开第二个 Claude 订阅号，怎么办？

一个 Google 账号只能订阅一个 Claude 账号，所以第二个号要换一个**没订阅过**的 Google 账号来付钱。

**如果手机里还登着上一个 Google 账号，Claude 里会提示「已经订阅过」。**这时先在手机里把那个 Google 账号退掉（手机「设置 → 账号」里移除，或在 Play 商店里切换账号），再用新的 Google 账号重新进 Claude 的订阅页。
