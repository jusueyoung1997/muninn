A quick reference for writing notes.

## Text

- **Bold**: `**bold**`
- *Italic*: `*italic*`
- `Inline code`: `` `code` ``

## Code blocks

````
```js
console.log('hello muninn');
```
````

## Lists

1. Ordered items use `1. 2. 3.`
2. Unordered items use `-` or `*`

## Quotes and links

> A blockquote starts with `>`.

Links use `[text](https://example.com)`.
